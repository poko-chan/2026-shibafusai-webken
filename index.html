Interaction 01

ダイアログの「出現演出」を比較

同じ「確認ダイアログ」でも、表示される速度・軌道・減速カーブ次第で、安心感・威圧感・ゲーム感が激変します。

A. 上質・バネ減速（推奨） 心地よい
scale(0.92→1) / cubic-bezier(0.16, 1, 0.3, 1)
B. 演出なし（0秒出現） 紙芝居感
transition: none; (即座に切り替え)
C. スマホ風ボトムシート 片手操作感
translateY(100%→0) / 画面下からせり出し
D. 警告シェイク（強い注意） 緊迫感
animation: modalShake 0.4s (画面揺れ)
E. 3Dフリップ立体出現 アトラクション感
perspective(1000px) rotateX(-30deg→0)
適用中のCSS定義 mode-refined 
.modal-container {
  transform: scale(0.92) translateY(12px);
  transition: transform 0.32s cubic-bezier(0.16, 1, 0.3, 1),
              opacity 0.32s ease-out;
}
検証エリア 下のボタンを押すとダイアログが出現します
【部員の解説】上質・バネ減速: 人の目は0.1秒未満の変化を「瞬間」と認識し、0.5秒を超えると「遅延」と感じます。0.3秒で92%からわずかに手前に飛び出す演出は、最も自然で高級感のあるUIの鉄則です。
Interaction 02

ボタンの「触感」を比較

マウスを重ねた瞬間（hover）と押した瞬間（active）の戻り速度で、物理的な重さの錯覚が生まれます。

1. スプリング・バウンス 心地よい反発
cubic-bezier(0.34, 1.56, 0.64, 1) 0.25s
2. 機械的等速 (Linear) ロボット的
transition: all 0.8s linear;
3. もっさり重たい (2.0s) イライラ感
transition: all 2.0s ease-in-out;
4. トランジション無し カチコチ
transition: none;
BUTTON CSS spring 
.test-btn {
  transition: all 0.25s cubic-bezier(0.34, 1.56, 0.64, 1);
}
.test-btn:hover {
  transform: translateY(-3px) scale(1.02);
  box-shadow: 0 8px 18px rgba(46, 125, 50, 0.25);
}
ボタン触感ステージ マウスを重ねたりクリックしてみてください
クリックカウント: 0 回
【部員の解説】バネの跳ね返り: cubic-bezierの3番目の値が1を超えると「目標地点を行き過ぎてから戻る（オーバーシュート）」効果が発生します。スマートフォンのアプリアイコンをタップした時の感触に近い心地よさが生まれます。
Interaction 03

イージング曲線・同時走行レース

「同じ1.6秒」でも、加速と減速のタイミングによって、目の錯覚で到着時間やスピード感が全く違って見えます。

1. linear（等速直線運動） 摩擦ゼロの無機質なロボット
等速
2. ease-in（助走加速） 重力落下・画面から立ち去る（退場）動き向き
加速
3. ease-out（ブレーキ減速） 飛び込んできて優しく止まる。画面への「入場」の基本
減速
4. cubic-bezier (0.34, 1.56, 0.64, 1)（バネ・行き過ぎ） 目標を超えて跳ね返る、弾力あるUI
跳躍
【部員の考察】なぜWebの世界では linear を嫌うのか？
現実世界では、車も人間も「徐々に加速し、ブレーキをかけて徐々に止まる」運動をします。等速運動（linear）は物理法則を無視しているため、人間の脳は無意識に「安っぽい・ぎこちない」と感じてしまいます。
Interaction 04

イージング調合ラボ

スライダーを動かして、自分だけの最適なアニメーション数値を実験してみましょう。

アニメーション時間 (Duration): 0.30s
バウンス強度 (Overshoot): 1.4
CUSTOM CSS BEZIER 
transition: all 0.30s cubic-bezier(0.34, 1.40, 0.64, 1);
カスタム調整ステージ 設定したイージングで跳ねます
スライダーを最大にするとアニメーションがゴムのように激しく跳ね、最小にすると減速せずに固い動きになります。「使いやすさと楽しさのバランス」を探してみてください。
