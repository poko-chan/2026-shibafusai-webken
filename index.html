リキッドグラスのUI挙動

上のDynamic Islandをタップするか、下のボタンでリキッド（液状バネ）のポップアップを試せます。

APPLIED CSS CURVE
.island-container {
  backdrop-filter: blur(25px) saturate(180%);
  transition: width 0.48s cubic-bezier(0.175, 0.885, 0.32, 1.275),
              height 0.48s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}

💡「リキッドグラス」をつくるCSSの秘密

AppleのDynamic Islandが「生きた水銀」のように見える理由は、単にサイズを広げているのではなく、ベジェ曲線に1.0を超えるオーバーシュート値（行き過ぎて戻る）を与えているからです。
さらに backdrop-filter: blur() と saturate() を重ねることで、奥の生成色が屈折したリキッドグラスの質感が完成します。
