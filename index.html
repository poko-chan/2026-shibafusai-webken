有機的な「リキッドグラス」の手触り

本物のiOSのように、アプリの交代時には中央へキュッと引き締まる「Squish」が発生し、展開時にはバネのオーバシュートで滑らかに開きます。

【部員の解説】不定期切り替えとUI演出:
規則正しい5秒周期ではなく、ランダムな時間間隔でタスクが入れ替わることで、「スマホの裏で誰かが動いている」ようなリアルな生命感が宿ります。
Interaction 01

ダイアログの「出現演出」を比較

同じダイアログでも、速度と減速カーブ次第で安心感や威圧感が劇変します。

A. 上質・バネ減速（推奨） 心地よい
scale(0.92→1) / cubic-bezier(0.16, 1, 0.3, 1)
B. 演出なし（0秒出現） 紙芝居感
transition: none; (即座に切り替え)
C. スマホ風ボトムシート 片手操作感
translateY(100%→0) / 画面下からせり出し
D. 警告シェイク（強い注意） 緊迫感
animation: modalShake 0.4s (画面揺れ)
E. 3Dフリップ立体出現 アトラクション感
perspective(1000px) rotateX(-30deg→0)
適用中のCSS定義 mode-refined 
.modal-container {
  transform: scale(0.92) translateY(12px);
  transition: transform 0.32s cubic-bezier(0.16, 1, 0.3, 1),
              opacity 0.32s ease-out;
}
検証エリア 下のボタンを押すとダイアログが出現します
【部員の解説】上質・バネ減速: 人の目は0.1秒未満の変化を「瞬間」と認識し、0.5秒を超えると「遅延」と感じます。0.3秒で92%からわずかに手前に飛び出す演出は、最も自然で高級感のあるUIの鉄則です。
Interaction 02

ボタンの「触感」を比較

マウスを重ねた瞬間と押した瞬間の戻り速度で、物理的な重さの錯覚が生まれます。

1. スプリング・バウンス 心地よい反発
cubic-bezier(0.34, 1.56, 0.64, 1) 0.25s
2. 機械的等速 (Linear) ロボット的
transition: all 0.8s linear;
3. もっさり重たい (2.0s) イライラ感
transition: all 2.0s ease-in-out;
4. トランジション無し カチコチ
transition: none;
BUTTON CSS spring 
.test-btn {
  transition: all 0.25s cubic-bezier(0.34, 1.56, 0.64, 1);
}
.test-btn:hover {
  transform: translateY(-3px) scale(1.02);
  box-shadow: 0 8px 18px rgba(46, 125, 50, 0.25);
}
ボタン触感ステージ マウスを重ねたりクリックしてみてください
クリックカウント: 0 回
【部員の解説】バネの跳ね返り: 押して離した瞬間の「ポヨン」とした反発が、ガラスの画面を物理ボタンのように錯覚させます。
